# Reading & Listening B2 – Lösungssuche

Kleine Webseite (`docs/`), mit der man HTL-Matura-Aufgaben (Englisch, B2, Reading & Listening)
von [aufgabenpool.at](https://aufgabenpool.at/srdp_lfs/index.php?id=en) per Titel oder erstem Satz sucht.
Die Lösungen stehen als **ausgeschriebener Text**, nicht als Buchstaben (A/B/C …).

- `docs/index.html` – die Seite (Suche mit Autovervollständigung, Filter Reading/Listening)
- `docs/data.js` – die Aufgaben und Lösungen

## Online stellen (GitHub Pages)
Settings → Pages → *Deploy from a branch* → Branch `claude/funny-carson-7fptoj`, Ordner `/docs` → Save.
Danach ist die Seite unter `https://ropperp.github.io/listeningreading/` erreichbar.
